# Prompt Assistant Beta Tester Guide

## What this is

This beta turns a rough one-line idea into a much better structured prompt.

Example:

- You type: `write a landing page for my AI assistant`
- On first launch, the app can route you into the right prompt pack
- You pick `Quick`, `Guided`, or `Expert`
- The app asks a few smart follow-up questions
- Then it builds a stronger prompt you can copy and use
- It also shows the score jump and why the prompt improved

## What testers should do

1. Double-click `start_prompt_assistant.bat`
2. If the pack picker appears, choose the use case that fits you best
3. Type one rough prompt idea
4. Choose a mode:
   - `Quick` if you want the fastest upgrade
   - `Guided` if you want a balanced prompt coach
   - `Expert` if the prompt is important and needs more structure
5. Click `Analyze Prompt`
6. Review the prompt health score, missing elements, and suggested pack matches
7. Answer or skip the short follow-up questions
8. Review:
   - the final structured prompt
   - the score change
   - the `Why this improved` panel
9. Open `History` to revisit saved prompts
10. Open `Library` to try curated prompt packs or refresh open-source prompts from the web
11. In `Library`, check the template fields, missing-element helpers, and repair hints
12. Use:
   - `Copy` to copy it
   - `Save` to save it
   - `Refine Again` to tighten it further

## What feedback we want

- Was it fast or annoying?
- Did the follow-up questions feel useful?
- Did the final prompt feel better than your first draft?
- Did the `Quick`, `Guided`, and `Expert` modes feel meaningfully different?
- Did the score and `Why this improved` section build trust?
- Did the first-run pack picker put you in the right place fast?
- Were the image/video subcategories useful enough?
- Did prompt history and the library feel useful or distracting?
- What confused you?
- What should be easier?

Use [BETA-FEEDBACK-FORM.md](./BETA-FEEDBACK-FORM.md) if you want a simple template to reply with.

## Notes

- This beta is local-first.
- Your prompt stays on the machine unless a live provider mode is added and chosen later.
- If the launcher says Python is missing, install Python for Windows and reopen the app.
