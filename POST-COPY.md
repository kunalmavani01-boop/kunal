# PROMPTER Posting Copy

## One-line positioning

`PROMPTER is a local-first browser app that turns rough prompts into stronger final prompts and helps people start faster with curated prompt packs.`

## Short hook options

- Better prompts without making people learn prompt engineering from scratch.
- Turn a messy AI prompt idea into something clearer and more usable.
- A local-first prompt refinement app for people who want better outputs with less prompt trial-and-error.

## Show HN

### Suggested title

`Show HN: PROMPTER - a local-first browser app to refine rough prompts`

### Alternate titles

- `Show HN: PROMPTER - turn rough prompts into clearer final prompts`
- `Show HN: PROMPTER - local-first prompt refinement with starter packs`
- `Show HN: PROMPTER - a browser app for improving rough AI prompts`

### Suggested body

```text
I built PROMPTER, a local-first browser app for people who have rough prompt ideas but want a clearer final prompt without doing the full prompt-engineering workflow by hand.

The MVP currently focuses on two things:
- refining rough prompts into stronger final prompts
- helping users start from curated prompt packs instead of a blank box

It is currently a local-first browser app and the repo includes the Windows launch path.

The feedback I would most love:
- is the refined prompt meaningfully better than the original
- does the starter pack flow make sense
- which audience this feels most useful for

GitHub:
https://github.com/kunalmavani01-boop/kunal/tree/codex/browser-mvp-prep
```
